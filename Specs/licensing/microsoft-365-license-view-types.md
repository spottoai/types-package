## Product display name contract

`Microsoft365LicenseRow.productName?: string` carries the engine-resolved product label independently of estimate currency. The validator accepts legacy omission and bounded strings, rejecting null or malformed supplied values. IDs/SKU codes retain their existing meaning; a name-only row has null quantities and does not prove inventory or commercial entitlement. This is one additive shared-contract update. The dictionary and resolver remain entirely in the engine. See the [canonical naming policy](../../../core/specs/licensing/microsoft-365-license-view/microsoft-365-license-view.md#microsoft-product-display-names). Validate CJS/ESM guards and consumers with the local built package before registry publication; delivery dependencies remain registry versions.
